## feat/webui

- Added `@picodata/ui-kit` with the public WebUI SDK types and design tokens
  generated from the host theme. Plugins can use the host's colors, shadows,
  border radius, and Montserrat font without copying theme values or depending
  on React or MUI. The independently versioned package is published to the
  Picodata Nexus npm registry on stable Picodata releases.
