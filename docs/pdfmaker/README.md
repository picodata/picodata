# Pdfmaker

## Общие сведения

Скрипт `pdfmaker` создает PDF-документы из собранных HTML-страниц
документации Picodata в текущей директории сайта. Для подготовки сайта
предварительно выполните:

```shell
pipenv run build # выполняет mkdocs build из песочницы
cd build
```

Скрипт принимает одну или несколько поддиректорий документации, например
`admin`, `architecture` или `dev`, находит внутри них страницы
`index.html`, очищает контент от элементов сайта и собирает единый
PDF-файл.

В выходном документе:

- есть титульный лист с логотипом Picodata, названием Picodata и названием документа;
- сразу после титульного листа есть содержание со списком разделов и номерами страниц;
- на титульном листе нет колонтитула и номера страницы;
- на остальных страницах есть верхний колонтитул с названием документа;
- номер страницы выводится справа внизу;
- гиперссылки удаляются, текст ссылок остается обычным текстом;
- блоки `См. также`, `Читайте далее` и `Читать далее` удаляются.

Поддерживаются два типа выходного документа:

- `-o` — `Руководство оператора`;
- `-a` — `Руководство администратора`.

Тип документа обязателен. Если не указать ни `-o`, ни `-a`, скрипт завершится с ошибкой.

## Синтаксис и примеры использования

Общий синтаксис:

```shell
./pdfmaker (-o | -a) [--pdf PATH] [--keep-html PATH] SECTION [SECTION ...]
```

Аргументы:

- `SECTION` — поддиректория с HTML-страницами документации. Можно указать одну или несколько поддиректорий.
- `-o`, `--operator` — создать `Руководство оператора`.
- `-a`, `--admin` — создать `Руководство администратора`.
- `--pdf PATH` — записать PDF в указанный путь.
- `--keep-html PATH` — сохранить промежуточный очищенный HTML для отладки.
- `--wide-table-mode vertical` — использовать вертикальное расположение заголовков в широких Markdown-таблицах

Примеры:

```shell
./pdfmaker -a admin espd/admin_manual
```

Создает руководство администратора из раздела `admin`, добавляет в него служебный раздел "Информационная безопасность" и сохраняет его в:

```text
PDF/AdministratorGuide.pdf
```

```shell
./pdfmaker -o tutorial/sql_examples tutorial/webui
```

Создает руководство оператора из разделов "Работа с данными SQL" и "Работа в веб-интерфейсе" и сохраняет его в:

```text
PDF/OperatorGuide.pdf
```

```shell
./pdfmaker -a admin/configure --pdf /tmp/configure.pdf
```

Создает PDF только из страницы/раздела `admin/configure` и сохраняет его в `/tmp/configure.pdf`.

```shell
./pdfmaker -a admin --pdf /tmp/admin.pdf --keep-html /tmp/admin.html
```

Создает PDF и дополнительно сохраняет промежуточный HTML, который можно использовать для проверки очистки контента.

Примеры ошибок:

```shell
./pdfmaker admin
```

Ошибка: не указан тип выходного документа.

```shell
./pdfmaker -o -a admin
```

Ошибка: одновременно указаны два типа выходного документа.

## Файл конфигурации

Pdfmaker позволяет указать исключения из сборки в файле конфигурации `pdfmaker.cfg`, наличие которого проверяется в текущей директории.
Файл конфигурации опционален — скрипт работает и без него. Возможности файла конфигурации:

- список подразделов (внутри статей), которые нужно исключить из сборки. Подраздел — блок после заголовка h2/h/3/h/4/h5 до следующего заголовка того же уровня
- список строк-шаблонов, которые нужно исключить из сборки. Строки, соответствующие указанным вхождениям, удаляются в составе соответствующих абзацев (<p></p>)
- при запуске скрипта производится строгая проверка подразделов (если подраздел указан неверно, то скрипт не начнёт работу). Проверка строк-шаблонов не производится.

Пример файла конфигурации поставляется в текущей директории.

## Установка зависимостей скрипта

## Автоматическая установка

Все зависимости Pdfmaker уже указаны в ../Pipfile. Перейдите на уровень выше и установите их:

``` shell
pipenv sync -d
```

## Установка вручную

```shell
python3 -m pip install beautifulsoup4 reportlab Pillow cairosvg
```

## Назначение зависимостей

- `beautifulsoup4` - разбор и очистка HTML;
- `reportlab` - генерация PDF;
- `Pillow` - чтение размеров PNG/JPEG-изображений;
- `cairosvg` - конвертация SVG-логотипа и SVG-диаграмм в PNG для вставки в PDF.

## Прочее

Скрипту также нужен установленный TTF-шрифт с поддержкой кириллицы. Он
ищет DejaVu Sans или Noto Sans в стандартных системных путях. Если таких
шрифтов нет, установите один из пакетов шрифтов вашей ОС, например
DejaVu Sans или Noto Sans.

Минимальная проверка после установки:

```shell
./pdfmaker -a admin/configure --pdf /tmp/configure.pdf
```

Если команда завершилась сообщением `PDF создан: ...`, скрипт готов к работе.
