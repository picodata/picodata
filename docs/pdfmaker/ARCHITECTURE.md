# Внутреннее устройство Pdfmaker

Скрипт состоит из нескольких логических блоков.

## Разбор аргументов

Блок `parse_args()` использует стандартный модуль `argparse`.

Он проверяет:

- указан ли ровно один тип документа: `-o` или `-a`;
- указана ли хотя бы одна поддиректория;
- переданы ли корректные параметры командной строки.

## Поиск страниц документации

Блок `collect_pages()` принимает список поддиректорий и ищет в них все файлы `index.html`.

Порядок страниц определяется так:

- если есть файл `picodata_docs.html`, скрипт берет порядок страниц из его содержания;
- страницы, которых нет в общем содержании, сортируются по пути.

Повторяющиеся страницы удаляются.

## Очистка HTML

Блок `clean_article()` извлекает основной контент из:

```html
<article class="md-content__inner">
```

Затем он удаляет служебные элементы сайта:

- навигацию;
- кнопки редактирования;
- формы обратной связи;
- скрипты и стили;
- якорные ссылки заголовков.

Гиперссылки удаляются методом `unwrap()`: тег `<a>` исчезает, но его текст остается в документе.

Блоки `См. также`, `Читайте далее` и `Читать далее` удаляются функциями:

- `remove_related_blocks()`;
- `trim_inline_related_text()`.

Локальные изображения преобразуются в абсолютные `file://`-пути. Внешние
изображения из `http`/`https` не загружаются и заменяются текстовой
заглушкой.

## Генерация PDF

PDF создается библиотекой ReportLab.

Основные элементы:

- `register_reportlab_fonts()` — регистрирует TTF-шрифты с поддержкой кириллицы;
- `make_reportlab_styles()` — задает стили абзацев, заголовков, таблиц, кода, титула и содержания;
- `make_toc()` — создает содержание через `TableOfContents`;
- `make_doc_template()` — задает шаблон документа и собирает записи содержания из заголовков `h1`, `h2`, `h3`;
- `render_pdf_reportlab()` — собирает титульный лист, содержание и страницы документации в итоговый PDF.

Для титульного листа используется отдельный обработчик страницы без
колонтитула и номера. Для всех следующих страниц используется
обработчик, который добавляет верхний колонтитул и номер страницы справа
внизу.

## Обработка изображений

Изображения обрабатываются в `image_flowable()`.

- PNG/JPEG-изображения вставляются через ReportLab.
- SVG-изображения предварительно конвертируются в PNG через CairoSVG.
- Размер изображений ограничивается шириной области документа и высотой страницы.
- Если изображение невозможно обработать, вместо него вставляется текстовая заглушка.

## Обработка таблиц

Слишком широкие Makdown-таблицы автоматически уменьшаются (scale down) и рендерятся в HTML-стиле.
