# Коды ошибок S3R

Справочник для администратора и разработчика: что означает код ошибки, который плагин указывает в
ответе и в журнале, и какой ответ с ним получает клиент. Всего кодов 287.

## Где встречается код {: #where_codes_appear }

- В ответе эндпоинта S3: в конце сообщения об ошибке, в квадратных скобках, стоят имя и номер кода,
  например `[NoQuorum/20029]`, а за ними идентификатор запроса (см.
  [Ответы при отказе хранилища](../usage/errors.md#storage_errors)).
- В журнале инстанса: там же записаны подробности, которых нет в ответе клиенту.
- В консоли управления: она показывает русское название и текст ошибки из столбца «Что означает».

## Как читать таблицу {: #how_to_read }

| Столбец | Что в нём |
| --- | --- |
| Код, номер | имя и номер кода. Номер закреплён за кодом навсегда |
| Ответ S3 | статус HTTP и код ошибки S3, с которыми отвечает эндпоинт S3. Прочерк означает, что запросы S3 этот код не получают |
| Ответ API управления | статус HTTP и код ошибки [API управления](management_api.md#reply_format) |
| Временная | «да», если причина может пройти сама и повторный запрос имеет смысл |
| Что означает | название и текст ошибки. В фигурных скобках стоят поля, вместо которых подставляются значения |
