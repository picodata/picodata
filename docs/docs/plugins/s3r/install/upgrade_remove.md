# Обновление и удаление

Страница описывает, что возможно при смене версии плагина S3R и как удалить
плагин из кластера. Она нужна администратору, который планирует переход на
другую версию или выводит хранилище из эксплуатации.

## Обновление и откат {: #upgrade_and_rollback }

!!! warning "Ограничение"
    Поддерживаемой процедуры обновления кластера с данными нет. Отката к
    предыдущей версии плагина на кластере с данными также нет.

Выпуски и сборки между выпусками меняют схему таблиц плагина в существующих
файлах миграций, а не новыми миграциями. Поэтому кластер, установленный другой
версией или сборкой, разворачивается заново.

## Удаление {: #plugin_removal }

!!! danger "Параметр `WITH DATA` удаляет метаданные объектов"
    Параметр `WITH DATA` применяет миграции в обратном направлении и удаляет
    таблицы плагина вместе с
    метаданными объектов. Без метаданных
    содержимое объектов на дисках прочитать нельзя.

1. Отключите плагин:

    ```sql
    ALTER PLUGIN s3r 2.2.0 DISABLE;
    ```

    Команда завершается, когда [инстансы](../reference/glossary.md#instance) применили запись об отключении.
    Сервисы плагина останавливаются после этого.

2. Убедитесь, что сервисы остановлены: в журнале каждого инстанса появились
   строки

    ```
    s3r_api stopped
    s3r_meta stopped
    s3r_storage stopped: every task of its start has ended
    ```

    Остановка сервиса ждёт завершения всех его задач и каждые 5 секунд
    записывает в журнал строку
    `... is stopping: N task(s) still running after ...`.

3. Удалите плагин вместе с данными:

    ```sql
    DROP PLUGIN s3r 2.2.0 WITH DATA;
    ```

**Результат.** Таблицы плагина удалены. Файлы в директориях дисков
сохраняются: директории дисков очищаются отдельной операцией.
