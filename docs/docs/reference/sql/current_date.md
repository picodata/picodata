# CURRENT_DATE

Функция `CURRENT_DATE` возвращает значение типа [DATETIME] с текущей
датой, временем `00:00:00` и часовым поясом. Функция используется без
круглых скобок.

В отличие от PostgreSQL, результат имеет тип `DATETIME`, а не `DATE`.

!!! note "Примечание"
    Часовой пояс определяется настройками хоста с инстансом
    Picodata, к которому подключена пользовательская сессия. Часовой пояс хоста
    можно посмотреть командами `date +%Z` или `timedatectl`.

## Примеры {: #examples }

```sql
sql>  VALUES (CURRENT_DATE);
+--------------------------+
| COLUMN_1                 |
+==========================+
| 2025-09-23T00:00:00+0300 |
+--------------------------+
(1 rows)
```
