# CURRENT_TIMESTAMP

Функция `CURRENT_TIMESTAMP` возвращает текущую дату и время с часовым
поясом в виде значения типа [DATETIME]. Результат совпадает с
[LOCALTIMESTAMP](localtimestamp.md).

Функция `CURRENT_TIME` пока не поддерживается.

В качестве аргумента можно указать неотрицательное целое число,
определяющее точность дробной части секунд: от `0` до `6` знаков.
По умолчанию используется точность `6`. Значения больше `6`
также дают точность `6`.

!!! note "Примечание"
    Часовой пояс определяется настройками хоста с инстансом
    Picodata, к которому подключена пользовательская сессия. Часовой пояс хоста
    можно посмотреть командами `date +%Z` или `timedatectl`.

## Примеры {: #examples }

```sql title="Получение текущей даты и времени"
SELECT CURRENT_TIMESTAMP;
```

```sql title="Получение текущей даты и времени с точностью до миллисекунд"
SELECT CURRENT_TIMESTAMP(3);
```
