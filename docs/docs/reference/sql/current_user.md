# CURRENT_USER

Функция `CURRENT_USER` возвращает имя текущего пользователя в виде значения типа
[TEXT]. Это имя пользователя, с привилегиями которого выполняется запрос.
Функция используется без круглых скобок.

`CURRENT_USER` разрешено использовать в любых выражениях: в проекциях,
в условиях `WHERE`, в
`GROUP BY`, в `VALUES`, при вставке и обновлении данных, а также в
теле [процедуры](create_procedure.md). В теле процедуры функция
возвращает имя пользователя, вызвавшего процедуру, а не ее владельца.
В рамках одного запроса функция всегда возвращает одно и то же значение.

## Примеры {: #examples }

Вызов функции не требует привилегий, поэтому запрос:

```sql
SELECT CURRENT_USER;
```

вернет имя пользователя, от имени которого выполняется запрос.

Следующий запрос выведет только те строки таблицы, владельцем которых
является текущий пользователь:

```sql
SELECT * FROM notes WHERE owner = CURRENT_USER;
```
