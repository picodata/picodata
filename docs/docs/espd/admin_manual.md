# Информационная безопасность

## Действия по приемке поставленного ПО {: #acceptance }

Приемка поставленного ПО состоит из следующих действий:

- проверка требований к сырью, материалам и комплектующим;
- проверка комплектности;
- проверка комплектности и качества эксплуатационной документации;
- проверка маркировки и упаковки;
- проверка соответствия контрольных сумм.

## Проверка требований к сырью, материалам и комплектующим {: #components_verification }

Проверка проводится только для экземпляров изделия, поставляемых на
материальных носителях. Проверка проводится путем внешнего осмотра
CD/DVD-диска, USB-флеш-накопителя и упаковки. Проверка считается
успешной, если:

- для изготовления использовались диски типа CD-R/DVD-R с покрытием типа
  Printable;
- при внешнем осмотре USB-флеш-накопителя и диска на изделие не
обнаружено царапин, деформаций, расслоений и загрязнений на их рабочих
поверхностях.

## Проверка комплектности {: #completeness_verification }

При проверке комплектности состав изделия должен соответствовать
составу, представленному в документе «Picodata. Формуляр»
40429836.01.62.0 ТД.ФО.

## Проверка комплектности и качества эксплуатационной документации {: #docs_verification }

Проверка проводится путем сверки
комплектности эксплуатационной документации, а также путем открытия и
просмотра на рабочей станции эксплуатационной документации,
представленной на компакт-диске.

Проверка считается успешной, если:

- комплектность эксплуатационной документации соответствует составу,
приведенному в документе «Picodata. Формуляр» 40429836.01.62.0 ТД.ФО;
- эксплуатационная документация, представленная на компакт-диске,
открывается на рабочей станции и пригодна для чтения с экрана монитора и
вывода на бумажный носитель.

## Проверка маркировки и упаковки {: #package_verification }

Проверка проводится путем наличия маркировки.

Проверка считается успешной, если формуляр изделия содержит
идентификатор Системы сертификации средств защиты информации по
требованиям безопасности информации ФСТЭК России.

Требования к упаковке не предъявляются.

## Действия по проверке контрольных сумм {: #checksum_verification }

Проверка контрольных производится посредством сравнения контрольных сумм
дистрибутива и исполняемых файлов, указанных в документе «Picodata.
Формуляр» 40429836.01.62.0 ТД.ФО и результатом снятия контрольных
сумм ответственным специалистом пользователя изделия.

Расчет контрольных сумм осуществляется посредством использования программы
«gostsum v2.2.0» по алгоритму ГОСТ Р 34.11-2012 (gost-2012) из
состава сертифицированной операционной системы Astra Linux Special
Edition (сертификат ФСТЭК России № 2557, выдан 27 января 2012 года,
действителен до 27 января 2031 года).

## Действия по безопасной установке и настройке изделия {: #safe_install_verification }

Для безопасной установки и настройки изделия
аппаратная и программная часть среды функционирования должна
удовлетворять минимальным системным требованиям, указанным в документе
«Picodata. Формуляр» 40429836.01.62.0 ТД.ФО.

## Действия по реализации функций безопасности среды функционирования изделия {: #environment_verification }

Работа изделия должна обеспечиваться путем развертывания изделия в сертифицированной
операционной системе:

- ОС Альт 8 СП релиз 9 (сертификат соответствия ФСТЭК России № 3866);
- ОС Альт 8 СП релиз 10 (сертификат соответствия ФСТЭК России № 3866);
- ОС «РЕД ОС» версии 7 (сертификат соответствия ФСТЭК России №4060);
- ОС «РЕД ОС» версии 8 (сертификат соответствия ФСТЭК России № 4060);
- ОС «Astra Linux Special Edition» версии 1.7 (сертификат соответствия ФСТЭК России № 2557);
- ОС «Astra Linux Special Edition» версии 1.8 (сертификат соответствия ФСТЭК России № 2557);
- ОС РОСА «ХРОМ» платформа 2021.1 (сертификат соответствия ФСТЭК России №4818).

Настройка операционной системы должна быть выполнена в соответствии с
эксплуатационной документацией на операционную систему.
